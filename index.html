🗄️ Supabase Cloud Sync
Cara setup Supabase:
1. Buat akun gratis di supabase.com
2. Buat project baru → masuk ke Settings → API
3. Copy Project URL & anon/public key
4. Di Table Editor, buat tabel duitku_data (lihat panduan di bawah)
⚪ Belum dikonfigurasi
Biarkan kosong untuk menggunakan ID otomatis
📋 SQL UNTUK MEMBUAT TABEL (jalankan di Supabase → SQL Editor)
-- 1. Buat tabel
create table if not exists duitku_data (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);

-- 2. Aktifkan RLS
alter table duitku_data enable row level security;

-- 3. Buat policy akses penuh (anon key)
drop policy if exists "allow_all" on duitku_data;
create policy "allow_all" on duitku_data
  for all
  to anon, authenticated
  using (true)
  with check (true);
⚠️ Jika sync gagal, cek ini:
1. Sudah jalankan SQL di atas? (Table Editor → SQL Editor)
2. Pakai anon/public key, bukan service_role key
3. URL format: https://xxx.supabase.co (tanpa slash di akhir)
4. Policy RLS sudah di-create dengan role anon
⚡ Auto-sync: setiap kali data disimpan, otomatis dikirim ke Supabase
🔄 Bisa digunakan untuk sinkronisasi antar perangkat
